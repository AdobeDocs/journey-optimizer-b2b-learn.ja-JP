# アカウントリスト

アカウントリストを使用すると、ジャーニーオーディエンスとして使用できる、フィルタリングされたアカウントのリストを作成できます。

アカウントリストは、業界、規模、場所などの特定の基準にもとづいてアカウントをグループ化および整理するために使用されます。 これらのリストは、マーケティング活動のターゲティングとパーソナライゼーション、カスタマージャーニーのオーケストレーション、アカウントベースドマーケティング戦略の管理に[!DNL Journey Optimizer B2B Edition]で不可欠です。

[!DNL Journey Optimizer B2B Edition]内で、アカウントリストを作成、管理、維持して、マーケティングおよびセールス施策をサポートできます。 アカウントリストは、ターゲットオーディエンスの定義、顧客体験のパーソナライズ、主要なアカウントとのエンゲージメントの促進に活用できます。

アカウントリストを作成し、関連アカウントを追加したら、さまざまなチャネルや顧客接点で活用して、パーソナライズされたマーケティングエンゲージメントを提供することができます。 [!DNL Journey Optimizer B2B Edition]は、アカウントベースドマーケティング施策、カスタマージャーニー、その他のマーケティング活動のためにアカウントリストをアクティブ化する機能を提供します。

要約すると、[!DNL Journey Optimizer B2B Edition]のアカウントリストは、アカウントベースドマーケティングと顧客エンゲージメント活動を管理および調整するための基本的な要素です。 Adobe Marketo Engageを活用すれば、主要なアカウントのマーケティングエンゲージメントを整理、ターゲティング、パーソナライズし、有意義なインタラクションと関係を促進できます。
