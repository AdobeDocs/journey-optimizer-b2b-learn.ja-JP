# [!DNL Journey Optimizer B2B Edition] チュートリアル

[!DNL Journey Optimizer B2B Edition] を最大限に活用する方法について説明します。 ビルトインの生成 AI と業界最先端の自動化機能を使用して、アカウントと購買グループのジャーニーを調整し、特定のサービスに対する需要を最大限に高めます。

## 最新情報 {#whats-new}

* [購買グループの段階](/help/main/buying-groups/buying-group-stages.md)
  _単一ステージモデル内に複数の購買グループのライフサイクルステージを作成し、移行ルールを指定する方法について説明します。_

* [AEP イベントをリッスン](/help/main/account-journeys/journey-nodes/listen-for-aep-events.md)
  _アカウントジャーニーの任意のエクスペリエンスイベントを定義して使用します。_

* [有料メディアオーケストレーション](/help/main/account-journeys/journey-nodes/paid-media-orchestration.md)
  _ジャーニーを使用してユーザーを外部オーディエンスに移動し、その後、AEPの宛先カタログでサポートされている有料メディアの宛先にプッシュする方法を説明します。_
