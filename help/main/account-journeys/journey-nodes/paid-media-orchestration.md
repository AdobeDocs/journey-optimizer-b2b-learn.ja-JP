# 有料メディアオーケストレーション

顧客は、獲得、育成、販売資格を得るために、マルチチャネル戦略を通じて顧客とエンゲージしようとしています。 そのため、複数のチャネルからの連携が必要となり、マーケティング部門の手作業が多く、真の連携が欠ける可能性があります。

この課題の解決策として、[!DNL Journey Optimizer B2B Edition]は次の機会を提供します。

* 視覚的なジャーニーのインターフェイスを通じて、有料メディアのエンゲージメントを自動化し、有料メディアを設計できます。

* 単一のジャーニービューで、複数のチャネルをまたいでエンゲージメントを自動化できます。

* 様々なアカウントメンバーに最適なチャネルを通じて、アカウントの主要なメンバーと同時にエンゲージします。

このビデオでは、ジャーニーを使用してオーディエンスを外部オーディエンスに移動し、AEPの宛先カタログでサポートされている有料メディアの宛先にプッシュする方法を説明します。
