# 購買グループステージ

購買グループのステージとは、購買グループが意思決定プロセスを通過するさまざまなフェーズを表します。 このモデルは、機会を顧客に変換し、購買グループのメンバーに対する次善のアクションを特定することで、購買グループの進捗状況を追跡するように設計されています。

この機能を利用すれば、単一のステージモデル内で複数の購買グループのライフサイクルステージを作成し、移行ルールを指定することができます。 これらのルールを設定することで、購買グループがあるステージから別のステージに移動する方法を完全に制御できるようになります。 その後、ステージ移行をジャーニー内で自動化し、これらの機能を1つの強力なフローに組み合わせることができます。
