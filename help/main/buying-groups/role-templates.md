# 購買グループのロールテンプレート

[!DNL Adobe Journey Optimizer B2B Edition]で役割テンプレートを作成する方法を説明します。 これらのテンプレートは、購買決定に参加する人々、役割に割り当てられる方法、購買グループを完了させる要因を定義します。 このビデオでは、テンプレートの作成、役割の設定、公開について説明します。

このチュートリアルは、アカウントベースドマーケティングに[!DNL Journey Optimizer B2B Edition]を使用し、各アカウントの適切な関係者をターゲットにするマーケターと管理者を対象としています。

>[!VIDEO](https://video.tv.adobe.com/v/3433079/?learn=on)

次の方法について説明します。

* 購買グループの下にある役割テンプレートのインベントリを開き、ドラフトテンプレートとライブテンプレートを区別します。
* 一意の名前と説明を持つ新しい役割テンプレートを作成します。
* 重み付け、自動割り当て、完全性の要件などの役割を設定します。
* 役職での照合など、各役割の割り当て条件を定義します。
* すべての参加者を含めるには、意思決定者、実務担当者、インフルエンサーなど、役割をさらに追加します。
* 役割の優先順位を設定して、条件が一致する最初の役割にユーザーを割り当てます。
* 完全性スコア設定を使用して、各役割に必要なメンバー数を設定します。
* テンプレートを公開すると、そのステータスがLiveに変わり、ソリューションの関心に応じて利用できるようになります。

詳しくは、ユーザーガイドの「[購買グループの役割テンプレート &#x200B;](https://experienceleague.adobe.com/ja/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates)」を参照してください。
