# AEP イベントをリッスン

[!DNL Journey Optimizer B2B Edition] でAEP イベントをリッスンすると、アカウントジャーニーで任意のエクスペリエンスイベントを定義して使用できます。 管理者は、Adobe Experience Platform（AEP）ベースのイベント定義を設定できます。これにより、マーケターは、AEP エクスペリエンスイベントに反応するアカウントジャーニーを作成できます。 アカウントジャーニーでのAEP エクスペリエンスイベントの使用は、2 つの部分で構成されています。

* AEP イベント定義の作成と公開

* アカウントジャーニーでのAEP イベントの使用
