# アカウントリスト

アカウントリストを使用すると、ジャーニーオーディエンスとして使用できる、フィルターされたアカウントのリストを作成できます。

アカウントリストは、業界、サイズ、場所、その他の関連する属性など、特定の条件に基づいてアカウントをグループ化および整理するために使用します。 これらのリストは、マーケティングエンゲージメントのターゲティングとパーソナライズ、カスタマージャーニーの調整、および [!DNL Journey Optimizer B2B Edition] でのアカウントベースのマーケティング戦略の管理に不可欠です。

[!DNL Journey Optimizer B2B Edition] 内では、アカウントリストを作成、管理および維持して、マーケティングや販売の取り組みをサポートできます。 アカウントリストを使用すると、ターゲットオーディエンスの定義、顧客体験のパーソナライズ、主要アカウントとのエンゲージメントの促進を行うことができます。

アカウントリストを作成し、関連するアカウントを入力したら、様々なチャネルやタッチポイントをまたいでアクティブ化し、パーソナライズされたターゲット設定のマーケティングエンゲージメントを提供できます。 [!DNL Journey Optimizer B2B Edition] は、アカウントベースのマーケティングキャンペーン、カスタマージャーニーおよびその他のマーケティングアクティビティのアカウントリストをアクティブ化する機能を提供します。

要約すると、[!DNL Journey Optimizer B2B Edition] のアカウントリストは、アカウントベースのマーケティングおよび顧客エンゲージメントアクティビティを管理および調整するための基本要素です。 これにより、主要アカウントのマーケティングエンゲージメントを整理、ターゲット設定およびパーソナライズし、有意義なインタラクションと関係を促進できます。
